- The program is made to accept key stroke on the image to toggle between different modes. Here are some keys to be used:
```
't'=train  'c'=toggle classify  'e'=evaluate  'n'=toggle Hu/Embedding  's'=save  'q'=quit
```
- You can toggle between custom Hu Moment training or ResNet18 training model by pressing 'n'. Check CLI to make sure which mode you are at.
- Pressing 'c' will display object name, which is determined by the training data, on the image window. Depending on which mode you are at, either Hu Moment data or ResNet18 embedding will be used.
- Training ('t') and evaluating ('e') requires to type the object name of the image in the CLI. If you want to reset your training data, simply remove the .csv files in the data/ directory.

- There are 3 .csv generated by this program:
    - `confusion_matrix.csv`: Confusion matrix created by the evaluated objects during the program was running.
    - `embedding_data.csv`: Embedding data of the training data saved by pressing 't' while in Embedding mode.
    - `training_data.csv`: Total of 7 Hu Moments, aspect, extent and area of the object saved by pressing 't' while in Hu Moment mode.

- Saving will automatically generate confusion matrix on the CLI, using the evaluation data saved while the program was running.

- The model must be placed in `model/resnet18-v2-7.onnx` If file or directory name changes, change it on tha main script too.
