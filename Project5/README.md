OVERVIEW
--------
This project implements and evaluates two neural network architectures for
handwritten digit recognition on MNIST:
  1. A classic CNN (MNISTNetwork)
  2. A Vision Transformer (ViTNet / NetTransformer)

It also includes transfer learning to recognize Greek letters (α, β, γ)
using the pretrained CNN as a feature extractor.


FILES
-----
train_model.py
    Defines MNISTNetwork (CNN), trains it on MNIST, evaluates it, and saves
    the trained weights. Plots the first six test digits and training curves.

    Usage:
        python3 train_model.py [epochs] [learning_rate]
    Example:
        python3 train_model.py 5 0.01

test_model.py
    Loads a saved MNISTNetwork and evaluates it on:
      - Part 1: First 10 MNIST test examples (table + 3x3 grid plot)
      - Part 2: Custom handwritten digit images from a local directory

    Usage:
        python3 test_model.py [model_path] [custom_image_dir]
    Example:
        python3 test_model.py model/mnist_cnn.pth handwritten/

    Custom image filenames must encode the true label, e.g. handwritten_3.jpg

examine_model.py
    Loads a saved MNISTNetwork and visualizes:
      - The 10 learned 5×5 filters in conv1
      - The output of each filter applied to the first test image

    Usage:
        python3 examine_model.py [model_path]
    Example:
        python3 examine_model.py model/mnist_cnn.pth

greek_model.py
    Transfer learning from the MNIST CNN to classify Greek letters α, β, γ.
    Freezes conv1, conv2, and fc1; retrains only the output layer (fc2 → 3).

    Expects data directory with subdirectories: alpha/, beta/, gamma/
    containing .png images.

    Usage:
        python3 greek_model.py [mnist_model_path] [greek_data_dir] [epochs]
    Example:
        python3 greek_model.py model/mnist_cnn.pth greek_train/ 50

NetTransformer-template.py
    Vision Transformer (ViT) for MNIST. Implements patch embedding,
    multi-head self-attention via TransformerEncoder, and classification
    via a small MLP head. Supports CLS token or mean pooling aggregation.

    Usage:
        python3 NetTransformer-template.py

experiment.py
    Sweeps three ViT design dimensions and plots results:
      - Experiment 1: Patch size & stride  (7×7, 4×2, 3×2)
      - Experiment 2: Depth vs width       (shallow-wide, balanced, deep-narrow)
      - Experiment 3: CLS token vs mean pooling

    Saves per-experiment plots and a summary CSV.

    Usage:
        python3 experiment.py [epochs_per_config]
    Example:
        python3 experiment.py 10

    pip install torch torchvision matplotlib numpy Pillow


RECOMMENDED RUN ORDER
---------------------
1. python3 train_model.py          # train and save the CNN
2. python3 test_model.py           # evaluate on MNIST + custom digits
3. python3 examine_model.py        # visualize conv1 filters
4. python3 greek_model.py          # transfer learning on Greek letters
5. python3 NetTransformer-template.py  # train the Vision Transformer
6. python3 experiment.py           # run ViT ablation experiments
